Fórmulas matemáticas

  • Consumo = vazão × tempo
  • Consumo mensal = consumo diário × 30
  • Economia (%) = ((antes − depois) / antes) × 100

Desafio 1 (fácil): Uma família de 4 pessoas toma 2 banhos/dia de 10 min. Vazão = 9 L/min. Qual o consumo diário?

Desafio 2 (médio): Se reduzir cada banho para 5 min, qual a economia mensal (30 dias)?

Desafio 3 (difícil): Uma caixa d'água de 1.000 L abastece essa família. Em quantos dias ela esvazia com o consumo original?

💻 Programação Aplicada

Veja o código por trás da calculadora (JavaScript):

// Função que calcula o consumo diário (em litros)
function calcularConsumo(banhoMin, qtdBanhos, vazao, descargas, loucaMin) {
  const consumoBanho = banhoMin * qtdBanhos * vazao;
  const consumoDescarga = descargas * 12; // 12 L por descarga
  const consumoLouca = loucaMin * 6;      // 6 L por minuto
  return consumoBanho + consumoDescarga + consumoLouca;
}

🌱 Conscientização e Dicas

  • Feche a torneira ao escovar os dentes.
